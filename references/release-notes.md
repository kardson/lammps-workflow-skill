# v0.5.0 — Evidence contracts and local analysis

This release keeps the six-step research workflow and empirical/pretrained-ML
potential routes. Training is excluded. All 27 bundled CLI entrypoints are local;
none launches LAMMPS, SSH, performance tests or monitoring. Site adapters and
research evidence remain in private projects.

New capabilities include versioned record schemas and links, decision origins,
runtime/model/compatibility registries, source-matched knowledge routing,
input/model contracts, candidate and restart preparation, and validation case
planning or parsing. Static prediction packages, existing-output imports and
reference metrics keep failed samples and explicit comparison conventions.

Stage contracts, explicit trajectory clocks, streaming species balance and
disk-backed event/cohort accounting separate observations from inferred fates.
Replica source linkage and within-run block statistics withhold intervals when
required evidence is missing. Bounded sensitivity proposals can retain null
scientific choices without producing runnable inputs. Reports retain native
conclusion indices and reproduction configuration alongside HTML/PNG.

Existing basic input/log/model tools remain scoped diagnostics. Versioned records
do not silently migrate older files. Legacy artificial replica summaries remain
available as declared-only evidence; research-output intervals require per-replica
metadata and source binding. Reports without conclusion configuration now include
an empty partial index, never scientific acceptance. New output directories are
required; no original numeric artifacts are replaced.

Validation: 179 local tests ran (178 passed, one Windows symlink-creation skip),
33 isolated calls passed, and the current artificial local pipeline completed with
zero simulations, inference or remote contacts. This is not a clean dependency
resolver/Python-version matrix test. The separately documented reference engine
checks establish bounded functionality, not CdTe/GaAs potential accuracy or
accepted growth physics. See [examples](examples.md) and [capabilities](capabilities.md).

For upgrades, preserve the installed version and any local adaptations before
copying the complete release, including schemas, validation fixtures and tests.
The integrated demo imports its artificial fixtures from tests. Verify actual
installed file identities against the selected release; restarting or refreshing
the host's skill catalog may be necessary for discoverability. No engine changes
are included in a skill upgrade.
